EduRed CundiSantander

**Red Colaborativa de Recursos Educativos para Instituciones Oficiales y Privadas**

## Descripción
EduRed Santander es un repositorio digital diseñado para integrar una red de escuelas que permita a docentes, directivos y estudiantes compartir, organizar y reutilizar recursos educativos digitales de alta calidad.

## Objetivo General
Diseñar un repositorio digital colaborativo que facilite la creación, almacenamiento, búsqueda, intercambio y evaluación de recursos educativos entre las instituciones pertenecientes a una red de escuelas, fortaleciendo la calidad de los procesos de enseñanza y aprendizaje.

## Objetivos Específicos
- Centralizar todos los recursos educativos digitales.
- Facilitar el trabajo colaborativo entre docentes.
- Favorecer la inclusión mediante recursos accesibles.
- Reducir el tiempo de planeación docente.
- Promover el uso de Recursos Educativos Abiertos (REA).
- Compartir buenas prácticas pedagógicas.
